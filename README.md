# Zoë MV — Scout Still Knows

A storybook → song → music-video pipeline for **Zoë Elise Hartmann**, **David Cole Ashford**, and their dog **Scout**.

Built with Jimeng (即梦) for image / video / music / TTS, plus local assembly.

## Logline

> In San Jose, Zoë builds a startup and loses the boy who raised a dog with her — Scout is the witness who still knows the whole story.

## Characters

| Name | Role |
|------|------|
| **Zoë Elise Hartmann** | Berkeley grad · South Bay · mobile ads → founder of **LumenReach** |
| **David Cole Ashford** | California engineer · multi-millionaire family |
| **Scout** | The dog they fed and raised together (story symbol) |

## Repo layout

```
docs/STORY_BIBLE.md          # names, looks, backstory lock
docs/PHASE3_SHOTLIST.md      # 18×15s MiniMax-H3 shot list
docs/PHASE4_ASSEMBLY.md      # final MV concat + mux notes
storybook/STORYBOOK_BEATS.md # 8 storybook pages
characters/CHARACTER_SHEETS.md
lyrics/LYRICS_DRAFT.md
assets/images|video|audio/   # generated media (Phase 1b+)
```

## Pipeline

1. **Phase 1** — Story bible, beats, character sheets, lyrics draft ✅  
2. **Phase 1b** — Jimeng Seedream storybook stills  
3. **Phase 2** — SeedMusic + vocals / TTS  
4. **Phase 3** — MiniMax-H3 I2V clips (Plan A stills)  
5. **Phase 4** — Assemble MV (timeline + mux) ✅
